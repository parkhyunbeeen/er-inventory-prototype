랜덤 타워 디펜스

골드로 뽑은 랜덤 타워를 배치하고, 같은 타워를 합성해 등급을 올려
30 라운드를 막아내세요. 영웅 3개를 맞추면 전설 타워가 열립니다.

프로토타입 v0.1 · 1판 약 20분 (3배속 사용 시 7분 내외)

미션

전용 보스를 소환해 처치하면 골드를 받습니다. 놓쳐도 라이프는 깎이지 않습니다.

💰0골드
❤️0라이프
🌊0/ 30 라운드
🎲 소환 50G

선택된 타워 없음

빈 슬롯을 클릭하면 랜덤 타워가 소환됩니다. (소환 비용 50G)

조작 방법
  • 빈 슬롯 클릭 → 골드를 소모하고 랜덤 일반 타워 소환
  • 타워 클릭 → 선택(사거리 표시). 아래에 고급 / 희귀 / 영웅 합성 버튼이 각각 표시됩니다
  • 등급을 건너뛸 수 있습니다 — 같은 일반 타워가 8개면 한 번에 영웅까지
  • 합성 결과는 클릭한 타워의 위치에 생성됩니다
  • 영웅 타워를 클릭한 뒤 다른 영웅 2개를 추가로 클릭 → 조합표에 맞으면 전설 생성
  • ESC 또는 우측 상단 ⚙ → 설정창 (게임 일시정지)
  • 우클릭 → 선택 해제 / 1 2 3 → 배속 전환
전설 조합표

    강화

    등급별로 해당 타워 전체의 공격력이 올라갑니다. 레벨당 +5%.

    설정

    0으로 내리면 음소거됩니다.
