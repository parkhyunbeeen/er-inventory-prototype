# 랜덤 타워 디펜스 — 프로토타입 v0.1

골드로 뽑은 **랜덤 타워**를 격자에 배치하고, 같은 타워를 **합성**해 등급을 올려
**30 라운드**를 방어하는 HTML5 캔버스 게임입니다.

---

## ▶ 실행 방법

### 1. 그냥 게임만 하고 싶다면
**`game.html` 을 더블클릭**하세요. 그게 전부입니다.
설치할 것도, 서버도 필요 없습니다. (`start.bat` 도 같은 동작을 합니다)

### 2. 웹에서 열고 싶다면
아래 주소로 어느 기기에서나 접속할 수 있습니다.

https://claude.ai/code/artifact/3655583c-36b8-453a-a29a-6052b01b9882

### 3. 다른 사람에게 링크로 공유하려면
깃허브에 올리면 `https://아이디.github.io/저장소/` 주소가 생깁니다.
설치 없이 링크만으로 플레이 가능합니다. → **`GITHUB.md`** 참고

### 4. 코드를 수정하며 개발하려면
`src/` 폴더가 기능별로 분리된 원본입니다.
수정 후에는 `build.md` 안내대로 다시 합쳐 `game.html` 에 반영하세요.

> `src/index.html` 은 ES 모듈을 쓰기 때문에 더블클릭으로는 열리지 않습니다.
> 로컬 서버가 필요하며, 서버 없이 그냥 하고 싶다면 `game.html` 을 쓰세요.

## 🎮 조작

| 조작 | 동작 |
|---|---|
| 빈 슬롯 클릭 | 50G 소모, **랜덤 일반 타워** 소환 (소환은 이 방법뿐) |
| 타워 클릭 | 선택 (사거리 표시) |
| `⬆ 고급/희귀/영웅 조합` | 같은 계열·등급 **2 / 4 / 8개** → **클릭한 자리**에 생성 |
| 영웅 3개 연속 클릭 | 조합표에 맞으면 `★ 전설 합성` 활성화 |
| 좌측 미션 `도전` | 전용 보스 소환 → 처치 시 골드 (놓쳐도 라이프 안 깎임) |
| 우측 `강화` | 등급별 공격력 강화 (레벨당 +5%) |
| `💰 판매` | 투입 비용의 50% 환급 |
| `우클릭` | 선택 해제 |
| `ESC` 또는 우측 상단 `⚙` | **설정창** (게임 일시정지 · 사운드 · 게임 나가기) |
| `⏩ 바로 시작` | 준비 시간(20초)을 건너뛰고 즉시 전투 (최대 15G 보너스) |
| `▶ 배속` 버튼 / `1` `2` `3` | 진행 속도 1 → 2 → 3배속 전환 (재시작해도 유지) |

## 📊 게임 규칙 요약

- **등급**: 일반 → 고급 → 희귀 → 영웅 → **전설** (영웅 3개 조합)
- **합성**: 등급을 건너뛸 수 있습니다. 같은 일반 타워 **8개면 한 번에 영웅**까지
- **계열**: 궁수(단일) / 포탑(광역) / 서리(둔화) / 전격(연쇄) — 각 25% 확률

### 전설 4종 — 역할이 겹치지 않게 나눴습니다

| 전설 | 조합 | 역할 |
|---|---|---|
| 폭풍의 첨탑 | 궁수 + 전격 + 서리 | **범위 기절** — 적을 한곳에 묶음 |
| 빙하 성벽 | 포탑 + 서리 + 궁수 | **범위 둔화** — 흩어지지 않게 붙잡음 |
| 작열 요새 | 포탑 + 전격 + 궁수 | **광역 섬멸** — 뭉친 적을 녹임 |
| 공허 프리즘 | 포탑 + 서리 + 전격 | **방어 무시** — 보스 전용 딜러 |

기절로 묶고 → 둔화로 붙잡고 → 광역으로 정리하는 것이 최종 구도입니다.
단, 보스류는 기절 저항(35~65%)이 있어 이 구도만으로는 부족합니다.

### 미션 (좌측)

| 미션 | 개방 | 보상 |
|---|---|---|
| ◆ 중간 보스 토벌 | 5라운드마다 | `180 + 26 × 라운드` |
| ✦ 엘리트 처단 | 15라운드 · 1회 | 900G |
| ❖ 문지기 격파 | 25라운드 · 1회 | 2,200G |

### 강화 (우측)

| 등급 | 최대 | 비용 | 최대 효과 |
|---|---|---|---|
| 일반 | 5 | 1 × 레벨 | +25% |
| 고급 | 10 | 2 × 레벨 | +50% |
| 희귀 | 15 | 3 × 레벨 | +75% |
| 영웅 | 20 | 4 × 레벨 | +100% |
| 전설 | 30 | 5 × 레벨 | +150% |

- **승리**: 30 라운드 방어 완료 / **패배**: 라이프 0
- 보스는 10(1기) · 20(2기) · 30(2기) 라운드에 등장 (통과 시 라이프 −3)

## 🔧 자주 쓸 튜닝 값 (`src/js/data/config.js`)

```js
merge.required      // 합성에 필요한 개수 (현재 2, 3으로 바꾸면 정통 방식)
wave.finalWave      // 최종 라운드 (현재 30)
wave.hpGrowth       // 6라운드~ 적 체력 배율 (현재 1.32 — 낮추면 쉬워짐)
wave.bossHpGrowth   // 보스 전용 체력 배율 (현재 1.20)
wave.bossCount      // 라운드별 보스 수 { 10:1, 20:2, 30:2 }
upgrade             // 등급별 강화 최대 레벨 / 비용 / 레벨당 효과
economy.summonCost  // 소환 비용 (현재 50 고정)
life.start          // 시작 라이프 (현재 20)
wave.prepTime       // 라운드 간 준비 시간 (현재 20초)
speed.options       // 배속 단계 (현재 [1, 2, 3])
```

브라우저 콘솔에서 즉시 실험할 수도 있습니다:
```js
__GAME__.state.gold = 99999;
__GAME__.state.upgrades = [5,10,15,20,30];   // 전 등급 만렙
__GAME__.CONFIG.wave.hpGrowth = 1.20;        // 난이도 낮추기
__GAME__.api.startMission('gatekeeper');     // 미션 강제 시작
```

## ✅ 현재 상태

M1~M7 완료. 자동 플레이 8회 중 **6회 클리어**(실패 2회 모두 30라운드),
라이프가 깎이기 시작하는 시점은 대부분 26라운드 이후 — 막판에 승부가 갈립니다.
1판 소요 시간은 1배속 20분 내외, 3배속이면 6~9분.
그래픽은 도형+색상 코드이며 컨셉 확정 시 `src/js/render/shapes.js` 한 파일만
교체하면 됩니다.

자세한 내용은 `docs/07_마일스톤.md` 참고.
