## 2. 설계 원칙

| 원칙 | 내용 |
|---|---|
| 데이터/로직 분리 | 밸런스 수치는 전부 `data/`. 로직 파일에는 숫자를 두지 않음 |
| 렌더/로직 분리 | 로직은 `shape` 문자열만 전달. 그리는 방법은 `shapes.js`만 앎 |
| 상태 단일화 | 모든 게임 상태는 `state.js`의 `state` 객체 하나 |
| 시스템 단위 분리 | 소환·합성·전투·라운드·경제·강화·미션이 서로를 직접 호출하지 않음 |
| UI 콜백 주입 | `initHud({merge, mission, upgrade})` 로 핸들러를 넘겨 순환 참조를 피함 |

### 강화 값이 타워에 붙지 않는 이유

`Tower.damage`는 **강화 이전의 기본값**입니다.
실제 피해량은 `upgrade.js`의 `towerDamage(tower)`가 계산합니다.

이렇게 한 이유는 강화가 **이미 배치된 타워에도 소급 적용**되어야 하기 때문입니다.
타워 생성 시점에 값을 굳혀 두면, 강화를 살 때마다 필드의 모든 타워를 순회하며
값을 다시 써야 하고 판매·합성 시 원본 값을 잃습니다.

## 3. 게임 루프 순서 (`main.js`)

```
requestAnimationFrame
 └ isRunning() 이 false면 시뮬레이션 건너뜀 (타이틀 / 일시정지)
 └ for (i < state.speed) update(dt)   ← 배속만큼 반복
    1. 토스트 타이머
    2. updateWave(dt)        스폰 / 탈출 / 라운드 종료 / 미션 개방
    3. enemy.update(dt)      이동 / 상태이상 (기절 시 이동 0)
    4. updateTower(dt)       타깃 탐색 / 발사 / 파동
    5. projectile.update(dt) 이동 / 명중 처리
    6. collectKills()        처치 정산 + 미션 성공 판정
    7. tickVisuals(dt)       이펙트 수명
 └ render(ctx)
 └ updateHud()
```

`dt`는 0.05초 상한. 탭 전환 후 순간 이동을 방지합니다.

## 4. 실행 / 빌드

- **실행**: `game.html` 더블클릭 (또는 `start.bat`)
- **개발**: `src/` 수정 → `build.sh` 실행 → `game.html` 갱신
- Node.js가 없다면 `game.html`을 직접 편집해도 됩니다 (`build.md` 참고)

## 5. 디버그 훅

```js
__GAME__.state          // 게임 상태 전체
__GAME__.CONFIG         // 설정값
__GAME__.api            // 내부 기능 직접 호출

__GAME__.state.gold = 99999;
__GAME__.state.upgrades = [5,10,15,20,30];   // 전 등급 만렙
__GAME__.state.speed = 3;
__GAME__.CONFIG.wave.hpGrowth = 1.20;        // 난이도 낮추기
__GAME__.api.startMission('gatekeeper');     // 미션 강제 시작
__GAME__.api.showGame();                    // 타이틀 건너뛰고 게임 화면
__GAME__.api.toggleSettings();              // 설정창 토글
__GAME__.state.volume = 0;                  // 음소거
```

`api`에 노출된 함수: `summonAt · mergeTo · mergeOptions · mergeLegendary ·
legendaryStatus · buyUpgrade · upgradeCost · startMission · refreshMissions ·
updateWave · updateTower · collectKills · startPrep · beginWave · resetState ·
tileIndex · isBuildable`

이 api는 자동 플레이 시뮬레이션(밸런스 검증)에도 그대로 쓰입니다.

## 6. 확장 시 손댈 곳

| 하고 싶은 것 | 수정할 파일 |
|---|---|
| 타워 계열 추가 | `data/towers.js` + `render/shapes.js`에 도형 추가 |
| 전설 추가 | `data/legendary.js` |
| 적 추가 | `data/enemies.js` + `data/waves.js` 편성 |
| 미션 추가 | `data/missions.js` (+ 전용 적을 `enemies.js`에) |
| 강화 조정 | `data/config.js`의 `upgrade` |
| 맵/경로 변경 | `core/grid.js`의 `WAYPOINTS` |
| 그래픽 교체 | `render/shapes.js` 만 교체 |
| 새 상태이상 | `entities/Enemy.js` + `systems/combat.js`의 `applyStatus` |
| 효과음 교체 | `systems/audio.js`의 `tone()` / `SFX` |
| 타이틀·설정창 | `render/screens.js` + `index.html` |
| 판 색상 | `render/renderer.js`의 `FIELD` 상수 |
