# L3. 레벨 기획

## 1. 맵

| 항목 | 값 |
|---|---|
| 격자 | 12 × 8 (타일 64px) |
| 캔버스 | 768 × 512 px |
| 경로 | 좌측 진입 → S자 3턴 → 우측 탈출 (고정 1종) |
| 배치 가능 슬롯 | **65칸** (전체 96칸 − 경로 31칸) |

### 경로 꺾임점 (타일 좌표)
```
(-1,1) → (9,1) → (9,4) → (2,4) → (2,6) → (12,6)
```
좌측 화면 밖에서 진입해 오른쪽으로 달리다 두 번 꺾여 내려오고,
다시 오른쪽 끝(GOAL)으로 빠져나갑니다.

정의 위치: `src/js/core/grid.js`의 `WAYPOINTS`

## 2. 라운드 편성 (총 30 라운드)

| 라운드 | 구성 |
|---|---|
| 1 ~ 4 | 일반형만 (적응 구간) |
| 5 ~ 9 | 일반형 60% + 고속형 40% |
| **10** | **보스 1기** + 장갑형 다수 |
| 11 ~ 19 | 일반형 45% + 고속형 30% + 장갑형 25% |
| **20** | **보스 2기** + 장갑형 다수 |
| 21 ~ 29 | 3종 혼합 (물량 증가) |
| **30** | **보스 3기** — 방어 성공 시 GAME CLEAR |

- 라운드 n의 기본 등장 수 `base = 6 + round(n × 1.05)` — 물량을 전반적으로 상향
- 보스 수는 `config.js`의 `wave.bossCount`로 지정 → 10라운드 1기 · 20라운드 2기 · **30라운드 2기**

## 3. 스폰 간격

| 적 | 간격(초) |
|---|---|
| 일반형 | 0.26 ~ 0.62 |
| 고속형 | 0.24 ~ 0.45 |
| 장갑형 | 0.26 ~ 0.45 |
| 보스 | 1.1 |

1~9라운드는 간격을 넉넉히 두고, 10라운드부터 촘촘해집니다.
후반 물량이 몰려오게 만들어 광역·기절 조합이 필요해지는 구조입니다.

## 3-1. 미션 등장

미션 보스는 웨이브 편성과 별개로, 플레이어가 좌측 패널에서 도전할 때만 등장합니다.
경로는 동일하며 라이프를 깎지 않고, 살아 있어도 라운드 진행을 막지 않습니다.

| 미션 | 개방 |
|---|---|
| 중간 보스 토벌 | 5 · 10 · 15 · 20 · 25 · 30 라운드 |
| 엘리트 처단 | 15 라운드 (1회) |
| 문지기 격파 | 25 라운드 (1회) |

## 4. 라운드 진행 규칙
- 준비 단계 **20초** → 자동으로 전투 시작
- `⏩ 바로 시작` 버튼으로 스킵 가능 (남은 초 × 3G, 최대 15G 보너스)
- 준비 시간이 긴 이유: 소환·합성·전설 조합을 여유 있게 판단하기 위함. 빠르게 진행하고 싶으면 스킵
- 스폰 대기열이 비고 필드에 적이 0이면 라운드 클리어
- 클리어 시 보너스 골드 지급 후 다음 준비 단계로

정의 위치: `src/js/data/waves.js`, `src/js/systems/wave.js`
