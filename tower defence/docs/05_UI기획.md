# L5. UI / UX 기획

## 0. 화면 흐름

```
[타이틀 화면]
   ├─ 시작하기 ──→ [게임 화면] ──┐
   └─ 설정 ──→ [설정창]          │
                                 │  ⚙ 클릭 또는 ESC
                                 ↓
                            [설정창 (일시정지)]
                                 ├─ 계속하기 ──→ 게임 복귀
                                 └─ 게임 나가기 ──→ 타이틀로
```

### 타이틀 화면
- 게임 이름 + 한 줄 설명
- **[▶ 시작하기]** — 새 판을 시작합니다 (누른 시점에 오디오가 켜집니다)
- **[⚙ 설정]** — 사운드만 조절하는 설정창

배경은 위쪽에서 녹색 빛이 번지는 그라디언트로, 게임 판의 잔디색과 이어집니다.

### 설정창 — 타이틀/인게임 공용

같은 창을 쓰되 상황에 따라 구성이 달라집니다.

| | 타이틀에서 열 때 | 인게임에서 열 때 |
|---|---|---|
| 제목 | `설정` | `설정 (일시정지)` |
| 사운드 바 | ✅ | ✅ |
| 게임 나가기 | ✖ | ✅ |
| 확인 버튼 | `확인` | `계속하기` |
| 게임 진행 | — | **멈춤** |

**여는 방법**: 우측 상단 **⚙** 클릭 또는 <kbd>ESC</kbd>
**닫는 방법**: <kbd>ESC</kbd> · `계속하기` · `✕` · 창 바깥 클릭

인게임에서 열면 캔버스가 어두워지며 `일시정지` 글자가 표시됩니다.
설정창이 열린 동안에는 숫자키 배속 전환 같은 단축키도 막힙니다.

> ESC가 설정창으로 배정되면서, **선택 해제는 우클릭**으로 옮겼습니다.

### 사운드 바
- 0 ~ 100 슬라이더, 기본값 50
- 값이 실시간으로 옆에 표시되고, 0이면 "음소거 상태입니다"로 안내가 바뀝니다
- 손을 떼면 클릭음이 한 번 울려 현재 음량을 귀로 확인할 수 있습니다
- 게임을 나갔다 다시 시작해도 **음량 설정은 유지**됩니다

## 1. 게임 화면 구성 — 3단 레이아웃

```
┌──────────────┬────────────────────────────────────┬──────────────┐
│    미션       │ 💰 4950  ❤️ 20  🌊 22/30       ⚙  │    강화       │
│              ├────────────────────────────────────┤              │
│ ◆ 중간 보스   │                                    │ 일반 Lv.5/5   │
│   [도전 700G] │        게임 캔버스 768×512          │  +25% [완료]  │
│              │                                    │              │
│ ✦ 엘리트      │                                    │ 고급 Lv.7/10  │
│   [완료]      ├────────────────────────────────────┤  +35% [16G]  │
│              │ [⏩ 바로 시작 (19.5s)] [▶ 1배속]     │              │
│ ❖ 문지기      ├────────────────────────────────────┤ 희귀 Lv.4/15  │
│   [잠김]      │ 일반 궁수탑 (일반)                  │  +20% [15G]  │
│              │ 공격력 10 (기본 8) · 공속 0.60s      │              │
│              │ [고급 2/2][희귀 4/4][영웅 8/8]       │ 영웅 Lv.3/20  │
│              │ [💰 판매 (+25G)]                    │ 전설 Lv.2/30  │
└──────────────┴────────────────────────────────────┴──────────────┘
```

폭 1290px 이하에서는 세로로 쌓이고, 사이드 카드가 가로 그리드로 재배치됩니다.

## 2. 좌측 — 미션 패널

각 미션은 카드 한 장으로 표시됩니다.

| 상태 | 테두리 | 태그 | 버튼 |
|---|---|---|---|
| 잠김 `locked` | 기본 | `5라운드마다 개방` / `25라운드 개방` | `잠김` (비활성) |
| 도전 가능 `ready` | 청록 강조 | `도전 가능` | `도전 (보상 700G)` |
| 진행 중 `active` | 금색 강조 | `진행 중` | `진행 중…` (비활성) |
| 완료 `done` | 흐림 처리 | `완료` | `완료` (비활성) |

반복 미션은 카드에 `클리어 N회`가 함께 표시됩니다.

## 3. 우측 — 강화 패널

등급별로 카드 한 장. 각 카드는 다음을 보여줍니다.

- 등급명 (등급 색상으로 표시)
- `Lv.현재/최대` 태그
- 현재 공격력 보너스 `+N%`
- 진행 바 (등급 색상)
- `강화 (비용G)` 버튼 — 골드가 부족하면 자동 비활성, 만렙이면 `최대 강화 완료`

## 4. 중앙 — 선택 정보 패널

타워를 선택하면 **도달 가능한 등급마다 합성 버튼이 따로** 표시됩니다.

```
[ ⬆ 고급 조합 ]  [ ⬆ 희귀 조합 ]  [ ⬆ 영웅 조합 ]
     2 / 2개          4 / 4개          8 / 8개
```

- 재료가 충분한 버튼만 활성화되고, 해당 등급 색으로 테두리·글자가 물듭니다.
- 부족한 버튼도 `3 / 4개`처럼 진행도를 보여줘 몇 개가 더 필요한지 알 수 있습니다.
- 강화가 적용된 타워는 `공격력 112 (기본 100)` 형태로 원래 값을 함께 표시합니다.

## 5. 조작 흐름

1. **빈 슬롯 클릭** → 골드 차감, 랜덤 일반 타워 소환, 자동 선택
2. **타워 클릭** → 선택(사거리 원 + 흰 점선), 하단에 정보 + 합성 버튼들
3. **합성 버튼** → 원하는 등급 선택 → 클릭한 타워 자리에 생성
4. **전설 조합** → 영웅 클릭 후 다른 영웅 2개 추가 클릭 → 조합 일치 시 버튼 활성
5. **판매** → 단일 선택 상태에서만 노출
6. **우클릭** 또는 경로 타일 클릭 → 선택 해제
7. **배속 버튼 또는 숫자키 1·2·3** → 진행 속도 전환 (재시작해도 유지)
9. **⚙ 또는 ESC** → 설정창 (게임 일시정지)
8. **좌측 미션 도전** / **우측 강화 구매** → 준비 단계·전투 중 언제든 가능

## 6. 상태 피드백

| 상황 | 피드백 |
|---|---|
| 소환 | 계열 색 링 이펙트 |
| 합성 | 재료 → 기준 타워로 광선, 등급 색 확산 링, "고급!" 텍스트 |
| 전설 완성 | 금색 대형 확산 + `★ 이름` + 토스트 2.5초 |
| **기절** | 적에 노란 점선 링 + 상단 `✳` |
| **파동 공격** | 타워 사거리 전체에 확산 링 |
| **미션 개방** | 토스트 `미션 개방 — 엘리트 처단` |
| **미션 성공** | 청록 확산 + `미션 성공 +900G` |
| 강화 구매 | 토스트 `희귀 강화 Lv.4/15 — 공격력 +20%` |
| 골드 획득 | 적 위치에서 `+8` 노란 텍스트 상승 |
| 라이프 감소 | 상단 토스트 |
| 마우스 오버 | 배치 가능 슬롯 초록 테두리 / 점유 슬롯 흰 테두리 |
| 배속 가속 중 | 배속 버튼 금색 강조 + ▶ 개수로 단계 표시 |
| 일시정지 | 캔버스가 어두워지고 `일시정지` 표시 |

## 8. 성능 메모

사이드 패널은 매 프레임 갱신되지만, `innerHTML`이 **실제로 바뀔 때만** 교체합니다
(`setHtml` 헬퍼). 그렇지 않으면 버튼이 매 프레임 재생성되어 클릭이 씹힙니다.
클릭은 컨테이너에 건 **이벤트 위임**으로 처리합니다.
