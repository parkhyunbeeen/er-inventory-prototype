# L1. 시스템 기획

## 1. 코어 루프

```
라운드 시작 → 적 등장/이동 → 타워 자동 공격 → 처치 보상(골드)
     ↑                                                    ↓
     └── 라운드 클리어 보너스 ← 소환 / 합성 / 강화 / 미션 ──┘
```

준비 단계(**20초**) 동안 소환·합성·강화·미션을 처리하고, 전투 단계에서 방어합니다.
`⏩ 바로 시작`으로 건너뛰면 남은 시간 × 3G(**최대 15G**)의 보너스를 받습니다.

## 2. 소환 시스템

| 항목 | 값 |
|---|---|
| 조작 | 빈 슬롯 **클릭** |
| 비용 | **50G 고정** |
| 결과 | 항상 **[일반]** 등급, 계열만 랜덤 |
| 계열 확률 | 4계열 **균등 25%** |

관련 코드: `src/js/systems/summon.js`

## 3. 합성 시스템 — 등급별 분리 조합

같은 계열·같은 등급 타워를 모아 **원하는 등급으로 한 번에** 올릴 수 있습니다.
버튼은 도달 가능한 등급마다 따로 표시됩니다.

**필요 개수 = 2 ^ (목표 등급 − 현재 등급)**

| 기준 타워 | 고급 조합 | 희귀 조합 | 영웅 조합 |
|---|---|---|---|
| 일반 | 2개 | 4개 | **8개** |
| 고급 | — | 2개 | 4개 |
| 희귀 | — | — | 2개 |

- 일반 타워 8개가 모이면 중간 단계를 거치지 않고 **한 번에 영웅**까지 갑니다.
- 재료는 클릭한 타워에서 **가까운 순서**로 자동 소모됩니다.
- 결과는 항상 **클릭한 타워의 슬롯**에 생성되고, 그 타워가 자동 선택됩니다.
- 재료 배수는 `data/config.js`의 `merge.required` 한 줄로 2↔3 변경 가능합니다.

관련 코드: `src/js/systems/merge.js`

## 4. 전설 합성 시스템

| 항목 | 값 |
|---|---|
| 조건 | **[영웅] 등급 타워 3개**의 계열 조합이 조합표에 존재 |
| 조작 | 영웅 클릭 → 다른 영웅 2개 추가 클릭 → `★ 전설 합성` |
| 결과 위치 | **첫 번째로 선택한 타워의 슬롯** |
| 실패 조건 | 조합표에 없으면 버튼 비활성 + "조합표에 없는 조합입니다" |

전설은 최종 등급이며 더 이상 합성되지 않습니다.

## 5. 배속 시스템

| 항목 | 값 |
|---|---|
| 단계 | **1 / 2 / 3배속** |
| 조작 | 배속 버튼 클릭(순환) 또는 숫자키 `1` `2` `3` |
| 유지 | 재시작해도 선택한 배속이 유지됨 |

`dt`에 배속을 곱하지 않고 **한 프레임 안에서 시뮬레이션을 배속 횟수만큼 반복**합니다.

```js
for (let i = 0; i < state.speed; i++) update(dt);
```

`dt`를 곱하면 한 프레임 이동 거리가 커져 고속 투사체가 적을 지나쳐 버립니다.
반복 실행은 그 문제가 없고, 배속과 무관하게 밸런스가 완전히 동일합니다.

## 6. 미션 시스템 (좌측 패널)

플레이어가 직접 **전용 보스를 소환해** 처치하면 골드를 받는 선택형 콘텐츠입니다.

| 미션 | 개방 조건 | 대상 | 보상 |
|---|---|---|---|
| ◆ 중간 보스 토벌 | **5라운드마다** 반복 | 중간 보스 | `180 + 26 × 라운드` |
| ✦ 엘리트 처단 | **15라운드** · 1회 | 엘리트 | 900G |
| ❖ 문지기 격파 | **25라운드** · 1회 | 문지기 | 2,200G |

**규칙**
- 조건이 충족되면 카드가 `도전 가능` 상태가 되고 버튼이 활성화됩니다.
- 도전하면 미션 보스가 즉시 경로에 등장합니다. 준비 단계·전투 중 모두 가능합니다.
- **미션 보스는 라이프를 깎지 않습니다.** 놓치면 미션만 실패하고 다시 도전할 수 있습니다.
- 미션 보스가 살아 있어도 라운드는 정상적으로 진행/종료됩니다.
- 미션 보스의 체력은 보스 배율(`bossHpGrowth`)을 따릅니다.

관련 코드: `src/js/systems/mission.js`, `src/js/data/missions.js`

## 7. 강화 시스템 (우측 패널)

골드로 **등급별** 공격력을 올립니다. 해당 등급의 모든 타워에 즉시 적용됩니다.

| 등급 | 최대 레벨 | 비용 공식 | 총 비용 | 최대 효과 |
|---|---|---|---|---|
| 일반 | 5 | 1 × 레벨 | 15G | +25% |
| 고급 | 10 | 2 × 레벨 | 110G | +50% |
| 희귀 | 15 | 3 × 레벨 | 360G | +75% |
| 영웅 | 20 | 4 × 레벨 | 840G | +100% |
| 전설 | 30 | 5 × 레벨 | 2,325G | +150% |

- 레벨당 **공격력 +5%** (`upgrade.damagePerLevel`)
- 예: 전설 강화 3레벨째 비용 = 5 × 3 = **15G**
- 강화가 적용된 타워는 선택 패널에 `공격력 112 (기본 100)` 형태로 표시됩니다.

관련 코드: `src/js/systems/upgrade.js`

## 7-1. 화면 / 일시정지

| 상태 | 값 |
|---|---|
| `state.screen` | `'title'` 또는 `'playing'` |
| `state.settingsOpen` | 설정창이 열려 있는지 |

게임 루프는 `isRunning()` — **게임 화면이면서 설정창이 닫혀 있을 때만**
시뮬레이션을 돌립니다. 렌더링은 계속 하므로 멈춘 화면이 그대로 보입니다.

`resetState()`는 배속과 음량을 **유지**합니다. 플레이어 취향 설정이므로
판이 바뀌어도 초기화되지 않아야 합니다.

## 7-2. 사운드

외부 음원 파일 없이 **WebAudio 오실레이터로 합성**합니다.

| 상황 | 소리 |
|---|---|
| UI 클릭 | 짧은 상행 톤 |
| 타워 소환 | 낮음 → 높음 슬라이드 |
| 합성 | 2음 화음 (등급이 높을수록 고음) |
| 전설 완성 | 5음 상행 아르페지오 |
| 강화 구매 | 짧은 고음 |
| 미션 시작 / 성공 | 2음 / 3음 화음 |
| 라운드 시작 / 클리어 | 상행 톤 / 2음 화음 |
| 라이프 감소 | 하행 톱니파 |
| 게임 오버 / 클리어 | 4음 하행 / 5음 상행 |

- 브라우저 정책상 오디오는 사용자 클릭 이후에만 켜집니다.
  → **[시작하기]를 누른 시점**에 초기화합니다.
- 투사체 발사음은 넣지 않았습니다. 3배속에서 초당 수십 발이 나가면
  소음이 되기 때문입니다.
- 음량은 `state.volume`(0~1) 하나로 마스터 게인을 조절합니다.
- 실제 음원이 생기면 `audio.js`의 `tone()` 부분만 교체하면 됩니다.

관련 코드: `src/js/systems/audio.js`

## 8. 전투 시스템

**공격 방식 2종**

| 방식 | 설명 | 사용 타워 |
|---|---|---|
| 투사체형 | 타깃을 향해 발사체가 날아가 명중 판정 | 대부분 |
| **파동형(pulse)** | 사거리 전체를 즉시 내리침 | 폭풍의 첨탑 |

- **타깃팅**: 사거리 안에서 **가장 앞선 적**(경로 진행도 최대)
- **데미지**: `공격력 × 강화배율 − 방어력` (최소 1). `방어 무시`는 방어력을 0으로 계산
- **광역(splash)**: 착탄 반경 내 전체. 반경 40% 밖은 60% 피해
- **연쇄(chain)**: 가장 가까운 적으로 순차 전이, 매 전이마다 감쇠
- **둔화(slow)**: 이동 속도 % 감소. 더 강한 둔화가 우선
- **화상(burn)**: 초당 고정 피해 (방어력 무시)
- **기절(stun)**: 이동 속도를 **0**으로 만들어 제자리에 묶음

### 기절 저항
적마다 `stunResist`가 있어 기절 지속시간이 그만큼 줄어듭니다.

| 적 | 저항 | 1.1초 기절 시 실제 |
|---|---|---|
| 일반형 / 고속형 | 0% | 1.10초 |
| 장갑형 | 25% | 0.83초 |
| 중간 보스 | 35% | 0.72초 |
| 엘리트 | 50% | 0.55초 |
| 보스 | 55% | 0.50초 |
| 문지기 | 65% | 0.39초 |

저항이 없으면 전설 타워 하나로 모든 것이 영구 정지하므로, 보스류는 반드시 저항을 가집니다.

관련 코드: `src/js/systems/combat.js`
