# L0. 컨셉 기획

## 한 줄 정의
> 골드로 뽑은 랜덤 타워를 격자에 배치하고, 같은 타워를 모아 합성해 등급을 올려
> 30 라운드에 걸쳐 밀려오는 적을 막아내는 방어 게임.

## 장르
랜덤 타워 디펜스 (Random Tower Defense) + 머지(Merge) 성장

## 핵심 재미 (Core Fun)
1. **뽑기의 기대감** — 무엇이 나올지 모르는 랜덤 소환
2. **정리의 쾌감** — 흩어진 저등급 타워를 합성해 상위 타워로 압축
3. **선택의 긴장** — 지금 소환할까, 골드를 아껴 합성 재료를 노릴까
4. **조합의 발견** — 영웅 3개의 조합이 맞아야만 열리는 전설 타워

## 타깃 플레이 경험
| 구간 | 라운드 | 플레이어가 느껴야 할 것 |
|---|---|---|
| 도입 | 1~4 | 조작이 단순하다. 소환하면 바로 막힌다. |
| 성장 | 5~14 | 합성이 눈에 띄게 강해진다. 슬롯이 정리된다. |
| 압박 | 15~24 | 골드가 부족하다. 어디에 투자할지 고민된다. |
| 절정 | 25~30 | 전설 타워가 없으면 못 막는다. 조합을 완성해야 한다. |

## 아트 방향
**미정.** 프로토타입은 도형 + 색상 코드로만 구분합니다.
- 타워 계열 = 도형 + 본체색
- 타워 등급 = 테두리색 + 하단 점 개수 (전설은 ★)
- 적 종류 = 도형 + 색

컨셉 확정 시 `src/js/render/shapes.js` 한 파일만 스프라이트 드로잉으로 교체하면
나머지 로직은 손대지 않아도 됩니다.

## 목표 플레이 타임
1판(30 라운드) 기준 **13~17분**. 자동 플레이 시뮬레이션 6회 측정값.

## 프로토타입 범위 밖 (확장 후보)
- PvP / 협동 모드
- 타워 판매 외의 자원 순환(리롤, 강화석 등)
- 다중 맵 / 분기 경로
- 사운드, BGM
