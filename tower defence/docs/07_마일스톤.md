## M7에서 한 일

1. **등급별 분리 합성** — 고급/희귀/영웅 조합을 각각 버튼으로 분리.
   일반 8개면 한 번에 영웅까지 직행.
2. **미션 3종** (좌측 패널) — 중간 보스(5라운드마다) · 엘리트(15R) · 문지기(25R).
   전용 보스를 직접 소환하고 처치하면 골드. 놓쳐도 라이프는 안 깎임.
3. **등급 강화 5종** (우측 패널) — 일반/고급/희귀/영웅/전설 각각 5/10/15/20/30레벨.
   비용은 등급 기본값(1~5)의 배수로 상승. 레벨당 공격력 +5%.
4. **전설 역할 재설계** — 폭풍의 첨탑을 연쇄딜러 → **범위 기절기**로 변경.
   빙하 성벽과 역할이 겹치던 문제를 해결하고, "적을 한곳에 묶어 광역으로 정리"하는
   최종 구도를 만들었습니다. 보스류에는 기절 저항을 부여해 무력화를 방지.
5. **밸런스 재조정** — 일반 라운드 상향(체력 배율 1.21 → 1.32, 물량 +30%),
   보스는 별도 배율(1.20)로 분리하고 30라운드 보스를 3기 → 2기로 하향.
   1~5라운드는 완만한 배율(1.15)을 적용해 초반 사고사 제거.

## 자동 검증 결과

| 항목 | 결과 |
|---|---|
| 콘솔 에러 | 없음 |
| 등급별 합성 (2/4/8개 → 고급/희귀/영웅) | 3종 모두 정상, 클릭한 슬롯에 생성 |
| 전설 조합 4종 | 4/4 정상, 첫 선택 슬롯에 생성 |
| 잘못된 조합 거부 | 정상 (버튼 비활성 + null 반환) |
| 강화 비용 (일반 1+2 / 전설 5 = 8G) | 정확히 8G 차감 |
| 미션 개방/도전/보상 | 3종 정상 · 보스 소환 및 보상 지급 확인 |
| 기절 | 최대 **25마리 동시 정지** — 묶어서 때리는 구도 성립 확인 |
| 기절 저항 | 저항 55% 적용 시 2초 → 0.9초로 정상 감소 |
| 30라운드 클리어 (AI 8회) | **6/8 성공**, 실패 2회 모두 30라운드 |
| 라이프 감소 시작 시점 | 대부분 26라운드 이후 |

## M8에서 한 일

1. **타이틀 화면** — 시작하기 / 설정. 게임이 바로 시작되지 않고 한 번 거칩니다.
2. **설정창** — 타이틀과 인게임이 같은 창을 공유하되, 인게임에서만
   `게임 나가기`가 붙고 게임이 **일시정지**됩니다. ⚙ 버튼과 ESC 둘 다로 열립니다.
3. **사운드** — 외부 음원 없이 WebAudio로 합성한 효과음 12종.
   설정창의 사운드 바가 마스터 음량을 조절합니다.
4. **녹색 필드** — 게임 판을 잔디(녹색) + 흙길로 변경.
5. ESC가 설정창으로 배정되면서 **선택 해제는 우클릭**으로 이동했습니다.
