# L4. 밸런스 기획

## 1. 타워 기준 수치 ([일반] 등급)

| 계열 | 공격력 | 공속(초) | 사거리 | 부가 효과 |
|---|---|---|---|---|
| 궁수탑 | 8 | 0.60 | 190 | — |
| 포탑 | 18 | 1.40 | 150 | 스플래시 반경 45 |
| 서리탑 | 5 | 0.90 | 160 | 둔화 35% / 1.5s |
| 전격탑 | 10 | 1.00 | 170 | 2연쇄 / 감쇠 0.6 / 반경 95 |

등급 배율: 일반 ×1.0 → 고급 ×2.4 → 희귀 ×5.8 → 영웅 ×14.0
등급 보정: 사거리 +6%/단계, 쿨다운 −5%/단계
**최종 공격력 = 기본값 × 등급배율 × (1 + 강화레벨 × 0.05)**

## 3. 라운드 스케일링 — 3단 분리

일반 라운드는 올리고 최종 보스는 낮추기 위해 배율을 세 갈래로 나눴습니다.

| 대상 | 공식 | 30라운드 시점 |
|---|---|---|
| 일반 적 (1~5R) | `1.15^(n−1)` | — |
| 일반 적 (6R~) | `1.15^4 × 1.32^(n−5)` | 약 **1,120배** |
| **보스 / 미션 보스** | `1.20^(n−1)` | 약 **175배** |
| 처치 보상 | `1.06^(n−1)` | 약 5.7배 |
| 클리어 보너스 | `20 + n × 4` | 140G |

**왜 이렇게 나눴는가**

- **1~5라운드 완만(1.15)** — 초반에 서리탑만 3개 나오는 식의 사고사를 막습니다.
- **6라운드부터 1.32** — 전설 타워만 있으면 일반 라운드가 밋밋했던 문제를 해결합니다.
  25라운드 이후부터 실질적인 압박이 걸립니다.
- **보스는 1.20으로 분리** — 같은 배율을 쓰면 30라운드 보스가 감당 불가 수준이 됩니다.
  보스 수도 30라운드에서 3기 → **2기**로 낮췄습니다.

| 라운드 | 보스 수 |
|---|---|
| 10 | 1기 |
| 20 | 2기 |
| 30 | **2기** (기존 3기에서 하향) |

## 4. 경제 곡선

| 항목 | 값 |
|---|---|
| 시작 골드 | 200G (초반 4회 소환) |
| 소환 비용 | 50G 고정 |
| 판매 환급 | 투입 일반 타워 수 × 50G × 50% |
| 강화 총 비용 | 전 등급 만렙 기준 약 3,650G |
| 미션 총 보상 | 30라운드까지 약 6,000G |

판매 환급 예시: 고급 50G / 희귀 100G / 영웅 200G / 전설 1,200G

## 5. 목표 페이싱

| 시점 | 기대 상태 |
|---|---|
| 5 라운드 | 희귀 1~2기 · 중간 보스 미션 1회 |
| 10 라운드 | 영웅 1기 · 일반/고급 강화 만렙 |
| 15 라운드 | 첫 전설 · 엘리트 미션 |
| 25 라운드 | 전설 4종 확보 · 문지기 미션 |
| 26~30 라운드 | **실질 승부 구간** — 라이프가 깎이기 시작 |

## 6. 검증 결과 (자동 플레이 시뮬레이션 8회)

시뮬레이션 AI는 소환 → 최고 등급 즉시 합성 → 전설 조합 → 강화 구매 →
미션 도전을 모두 수행하는, 사람보다 실수가 적은 플레이를 합니다.

| 항목 | 결과 |
|---|---|
| 클리어 | **6 / 8 성공** (실패 2회는 모두 30라운드) |
| 잔여 라이프 | 3 ~ 20 |
| 라이프가 깎이기 시작하는 시점 | 대부분 **26라운드 이후** |
| 플레이 타임 | 16 ~ 25분 (1배속 기준 · 3배속이면 6~9분) |
| 생성 전설 수 | 20 ~ 23기 |
| 초반 사고사 | 0회 |

전 구간 라이프가 만땅으로 유지되던 이전 밸런스에서, **막판 5라운드에 승부가
갈리는** 형태로 바뀌었습니다.

## 7. 튜닝 포인트

난이도를 바꾸고 싶다면 `src/js/data/config.js`에서:

| 목적 | 수정할 값 |
|---|---|
| 중후반 난이도 ↓ | `wave.hpGrowth` (현재 1.32 → 1.28) |
| 중후반 난이도 ↑ | `wave.hpGrowth` (현재 1.32 → 1.35) |
| 보스만 쉽게/어렵게 | `wave.bossHpGrowth` (현재 1.20) |
| 보스 수 조정 | `wave.bossCount` (`{10:1, 20:2, 30:2}`) |
| 초반 난이도 | `wave.earlyGrowth` / `wave.earlySoftWaves` |
| 강화 효율 | `upgrade.damagePerLevel` (현재 0.05) |
| 강화 비용 | `upgrade.tiers[].costBase` |
| 미션 보상 | `data/missions.js`의 `reward` |
| 성장 속도 | `merge.required` (2 → 3이면 훨씬 느려짐) |
| 게임 길이 | `wave.finalWave` |
