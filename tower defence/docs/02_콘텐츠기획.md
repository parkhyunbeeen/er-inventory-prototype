## 3. 전설 타워 (4종) — 역할 분리

기본 계열 4종에서 3개를 뽑는 조합은 4가지. 네 타워의 역할이 서로 겹치지 않도록 설계했습니다.

| 전설 타워 | 조합 | 도형 | 역할 | 핵심 능력 |
|---|---|---|---|---|
| **폭풍의 첨탑** | 궁수 + 전격 + 서리 | 별 | **제어** | 범위 전체 **기절 1.1초** |
| **작열 요새** | 포탑 + 전격 + 궁수 | 폭발형 | **섬멸** | 반경 85 광역 + 화상 70/s |
| **빙하 성벽** | 포탑 + 서리 + 궁수 | 방패 | **지연** | 반경 70 광역 + 둔화 60% |
| **공허 프리즘** | 포탑 + 서리 + 전격 | 프리즘 | **대보스** | 방어 무시 4연쇄 |

| 전설 타워 | 공격력 | 공속 | 사거리 | 공격 방식 |
|---|---|---|---|---|
| 폭풍의 첨탑 | 90 | 1.60s | 200 | **파동형** (사거리 전체 즉시 타격) |
| 작열 요새 | 300 | 1.10s | 200 | 투사체 + 스플래시 |
| 빙하 성벽 | 150 | 0.80s | 215 | 투사체 + 스플래시 |
| 공허 프리즘 | 230 | 0.70s | 220 | 투사체 + 연쇄 |

### 설계 의도 — 최종 조합의 형태

기존에는 폭풍의 첨탑(연쇄+둔화)과 빙하 성벽(광역 둔화)의 역할이 겹쳤습니다.
폭풍의 첨탑을 **범위 기절기**로 바꾸면서 최종 방어선이 이런 형태가 되도록 했습니다.

```
폭풍의 첨탑 → 사거리 안의 적 전체를 1.1초마다 묶는다
                     ↓  적이 한 지점에 쌓인다
빙하 성벽   → 기절이 풀려도 60% 둔화로 흩어지지 않게 붙잡는다
                     ↓
작열 요새   → 뭉친 적 무리를 광역 + 화상으로 한꺼번에 녹인다
공허 프리즘 → 방어력 높은 보스만 따로 관통 피해로 처리한다
```

적 체력이 아무리 올라가도 **한곳에 묶어놓고 광역으로 때리는** 구도가 성립하므로,
후반 물량 라운드의 해법이 됩니다. 대신 보스류는 기절 저항을 가져 이 구도가
그대로 통하지 않고, 공허 프리즘 같은 단일 딜러가 따로 필요합니다.
